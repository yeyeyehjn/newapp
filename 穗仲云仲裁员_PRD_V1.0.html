一、基础信息

项目 说明
对应原型 微信小程序：首页工作台、案件列表、案件详情、任务中心、声明承诺书、笔录签名、延期审批、文书签名等 17 个功能模块
接入方式 微信小程序，底部 4 Tab 导航（首页 / 案件 / 待办 / 我的）+ 多级子页面
操作角色 广仲在聘仲裁员（首席 / 独任 / 边裁）
所属模块 穗仲云 · 仲裁员移动端
页面入口 微信小程序首页（工作台），底部 Tab 切换至案件、待办、我的
核心目标 仲裁员在移动端完成案件办理、待办处理、文书签章、庭审排期、延期审批、数据统计、个人档案管理等全流程仲裁业务

二、角色权限与统一规则

2.1 角色权限

  • 查询该仲裁员负责的案件、待办事项。

2.2 统一规则

签名规则：

  • 手写签名采用 HTML5 Canvas 画板，支持触摸与鼠标手写。

列表页通用规则：

  • 顶部搜索框 + 状态筛选 Tab（每个 Tab 带计数角标）。
  • 卡片式列表，状态徽章配色统一：待处理-琥珀色、已完成-绿色、已驳回-红色。
  • 空状态占位提示 + 清空搜索与过滤 操作按钮。

导航规则：

  • 所有子页面顶部采用微信小程序风格返回栏（左侧 返回 + 居中标题）。
  • 底部 4 Tab 常驻（首页 / 案件 / 待办 / 我的），待办 Tab 显示未处理数量红色徽章。

数据展示规则：

  • 金额智能格式化（超千万显示 千万元，超万显示 万元）。
  • 时间格式化与时间轴展示。
  • 统计图表采用 SVG 自绘（环形图、柱状图、进度条）。

本期暂不做：

  • 智云数字法庭的实时开庭功能为概念展示，正式开庭能力待后续版本对接。
  • 裁决书全文在线编辑（当前仅预览 + PDF 附件上传）。

其他规则：

  • 登录采用账号密码+手机/邮箱验证码或手机号码+人脸双因素校验，登录成功后自动跳转到首页工作台。
  • 退出登录需二次确认。

三、登录

3.1 页面结构

登录页采用「方式选择 → 多步表单」两级结构，先选择登录方式，再进入对应的双因素验证流程。

区块 规则
品牌区 顶部展示「穗」Logo 图标 +「广州仲裁委」品牌标识 + 标题「仲裁员端 · 安全登录」+ 引导文案
方式选择区 两张可选卡片：① 人脸识别登录（手机验证码 + 人脸活体识别）；② 账号密码登录（账号密码 + 绑定手机短信验证）
步骤指示器 进入表单后顶部展示 Stepper 进度条，标注当前步骤（共 2 步）
表单区 根据所选方式与步骤，动态展示对应字段（详见 3.2）
操作区 下一步 / 安全登录 主按钮 + 协议勾选 + 忘记密码入口
安全提示 底部展示「CA 盾加密通道 · 数据全程脱敏」

3.2 字段规则

3.2.1 人脸识别登录

步骤 字段 组件 必填 规则
第 1 步 手机号码 输入框（tel） 是 11 位手机号，校验正则 ^1[3-9]\d{9}$
第 1 步 短信验证码 输入框（tel） 是 6 位纯数字，右侧附「获取验证码」按钮（60s 倒计时）
第 2 步 已验证手机号 只读展示 — 回显第 1 步手机号，带「已验证」标识
第 2 步 人脸识别 采集区（点击触发） 是 点击开始活体采集，采集成功后显示「已采集」标识，支持「重新采集」

3.2.2 账号密码登录

步骤 字段 组件 必填 规则
第 1 步 仲裁员账号 输入框 是 去空格后长度 ≥ 2
第 1 步 登录密码 输入框（password） 是 长度 ≥ 6，右侧附「显示/隐藏」切换按钮
第 1 步 忘记密码 文本按钮 否 右下角入口，跳转找回流程
第 2 步 账号绑定手机号 只读展示 — 系统根据账号自动回填绑定手机号（脱敏显示，如 139****1234）
第 2 步 短信验证码 输入框（tel） 是 6 位纯数字，右侧附「获取验证码」按钮（60s 倒计时）

3.3 交互规则

方式选择：

  • 默认展示登录方式选择页，点击任一卡片进入对应登录流程。
  • 表单页左上角「返回」按钮：第 2 步返回第 1 步并清空验证码/人脸状态；第 1 步返回方式选择页并重置全部表单。

人脸识别登录：

  • 第 1 步：校验手机号格式 + 验证码为 6 位 → 通过后进入第 2 步；失败则「下一步」按钮置灰。
  • 第 2 步：点击采集区开始人脸活体识别（约 2.2s），采集完成后显示「人脸采集成功」。
  • 点击「安全登录」：校验手机号、验证码、人脸均已采集 → 调用 onLogin 写入登录态。

账号密码登录：

  • 第 1 步：校验账号（≥ 2 字符）+ 密码（≥ 6 位）→ 通过后系统根据账号查询绑定手机号（脱敏展示），进入第 2 步；失败则「下一步」按钮置灰。
  • 第 2 步：向绑定手机发送验证码（60s 倒计时），校验验证码为 6 位。
  • 点击「安全登录」：校验验证码通过 → 调用 onLogin 写入登录态。

验证码：

  • 「获取验证码」按钮仅在手机号合法且倒计时为 0 时可点击；点击后进入 60s 倒计时，倒计时期间按钮文案变为「Xs 后重发」。

登录成功：

  • 登录成功后自动跳转至首页工作台。

六、案件详情

6.1 页面结构

区块 规则
返回栏 左侧 返回 + 居中案号标题
渐变 Banner 展示案号、案由、案件状态，右侧显示该仲裁员在该案件的待办数，点击待办数显示待办清单，点击进入对应的待办详情页

6.2 各 Tab 展示规则

Tab 展示内容
基本信息 关键信息网格：立案日期、组庭日期、争议金额、仲裁费、办案秘书；秘书联系方式（电话/邮箱，点击一键复制，反馈 已复制）；案情摘要（AI 生成，带 AI生成，仅供参考 水印）
当事人 申请人 / 被申请人两区块，显示人数；每位当事人：属性（企业/自然人）、名称、证件类型及号码、手机、邮箱、法定地址
仲裁请求 事实和理由完整陈述；请求项编号列表（违约金、返还投资款、赔偿损失、仲裁费承担等）
主要材料 材料搜索（名称/类别/提交方）；按类别分组：申请书、申请人证据、被申请人证据、申请人答辩状、被申请人答辩状、其他材料；点击弹出预览弹窗，提供下载
文书签名 庭审笔录 PDF（从网上签名处获取）；仲裁裁决书 PDF（待签名/已签名）；签名流程：确认签名 → 成功反馈（提示语“签署成功”）
裁决书核阅 案件头部信息；文书概览（仲裁请求、答辩意见、举证质证）；核阅流转记录时间轴（角色头像/时间/意见/附件）；裁决书草稿版本管理（v1/v2 切换）；上传文书表单（提醒对象/备注/附件）；PDF 全屏预览弹窗

6.3 交互规则

  • 点击 Tab 标题 → 切换展示内容，支持横向滑动。
  • 支持从外部入口直接定位到指定 Tab（如文书签名列表进入时自动切到"文书签名"Tab，裁决书核阅列表进入时自动切到"裁决书核阅"Tab）。
  • 点击秘书电话/邮箱 → 复制到剪贴板，Toast 已复制。
  • 点击材料条目 → 弹出预览弹窗。
  • 文书签名 Tab → 走签名流程（见 6.4）；庭审笔录未签名时点击 → 跳转笔录签名详情页，签名完成后返回案件详情页"文书签名"Tab。
  • 裁决书核阅 Tab → 走核阅/上传流程（见 6.5）。
  • 待办面板中点击"裁决书核阅"待办 → 切换到"裁决书核阅"Tab（不跳转子页面）。

6.4 文书签名流程

  • 确认签名：点击后 loading 动画，调用 GDCA 签章接口
  • 签名成功：提示“签署成功”，并刷新签署状态

6.5 裁决书核阅流程

步骤 操作 规则
1 查看核阅流转记录 时间轴展示：秘书发起 → 一级核阅（退回/通过）→ 秘书修改中
2 查看裁决书草稿 支持 v1/v2 版本切换，查看裁决书全文

4 PDF 预览 全屏深色背景，模拟裁决书内容，带水印与页码，提供下载
